Features

Everything you need to test modern software

Argus handles any platform, any stack. One tool, one YAML format.

🗣️

Natural language steps

Write "Type hello into the editor" instead of find_element(By.ID, "editor").send_keys("hello"). The LLM figures out the how.

🔍

Structured assertions

Mix AI-driven steps with deterministic assertions (text_visible, exit_code_is, url_contains). Assertions never consult the model.

🤖

Free-roam bug hunting

argus roam turns the LLM loose to explore like a curious tester — opens menus, fills fields, tries edge cases, detects crashes and error dialogs automatically.

🧠

Adaptive Learning Engine

Builds a semantic graph of UI states and transitions across sessions. Vector search retrieves similar past experiences to guide the LLM — smarter exploration and targeted bug re-discovery over time.

🔄

Retry & flaky tracking

Set retries: 2 in your spec. Flaky steps are flagged so you know which tests are unreliable before they hit CI.

👁️

Multimodal or text-only

Argus auto-detects vision capability. Multimodal models get screenshots; text-only models fall back to the accessibility tree. Both work.

💰

Provider-agnostic + cost-aware

Ollama (free, local), Anthropic, OpenAI, Azure, Gemini, LiteLLM. Token tracking and cost estimation included for cloud providers.

👀

Watch mode

argus watch re-runs tests instantly on YAML save. The tightest feedback loop for test authoring.

📊

Web dashboard

argus serve serves a live dashboard of run history and roam sessions. See pass/fail trends without leaving the browser.

Adapters

Test anything

One YAML format, four execution environments.

🖥️ Desktop GUI Stable

Windows (UIA/pywinauto) and Linux (X11/Xvfb). Screenshots + accessibility tree. Handles WinUI3 apps and system singletons like explorer.exe.

🌐 Browser New

Playwright-powered. Chromium, Firefox, WebKit. Full DOM element access, screenshot support, URL and title assertions. Headless or headed.

⌨️ CLI New

Run any shell command. Assert on stdout, stderr, and exit code. Perfect for testing scripts, build tools, compilers, and data pipelines.

🪟 Native App GUI

The optional argus gui desktop app — a pywebview window with a live test runner, roam journal, provider checker, and token meter.

How it works

Hybrid-agentic execution

NL steps get the LLM. Assertions run deterministically. You get the best of both.

1

Argus launches the target

Starts the app (or attaches to an existing process) and takes an initial snapshot.

2

For each NL step: observe → act loop

The LLM sees a screenshot + accessibility tree, picks the best action (click, type, key…), Argus executes it, rinse and repeat until done.

3

Assertions run without the LLM

text_visible, exit_code_is, url_contains — these check the observation directly. Fast, deterministic, never hallucinates.

4

Teardown and report

Closes the app, saves JSON results to .argus/runs/, prints a summary with token usage and exit code.

notepad.test.yaml
# Desktop GUI test
name: Notepad smoke test
target:
  adapter: desktop-gui
  launch: notepad.exe
retries: 1

steps:
  - "Type 'hello from argus' into the editor"
  - assert:
      text_visible: "hello from argus"
  - "Open the File menu"
  - assert:
      element_exists:
        name: "Save"
        control_type: MenuItem
  - assert:
      window_title_contains: "Notepad"

teardown:
  - close
Free-roam mode

Let the AI find bugs you didn't think to look for

argus roam turns an LLM loose on your app with no script. It opens every menu, fills every field, tries edge cases — and files a detailed bug report when something looks wrong.

Cross-session memory means each run explores new ground instead of repeating the same path. Findings get auto-generated regression stubs you can refine and commit. 

# Desktop app
argus roam "notepad.exe" --minutes 10

# Web app
argus roam "http://localhost:3000" \
  --adapter browser --minutes 5

# CLI tool
argus roam "./my-script.sh" \
  --adapter cli --minutes 2

Knowledge Engine

Learns what to attack — every session

Argus builds a persistent graph of your app's UI surface and uses vector search to recall past observations, so each roam session is smarter than the last.

🗺️

State graph

Every unique UI state becomes a node; every action that transitions between states becomes an edge. Bug-prone zones are marked red and re-targeted on the next run.

🔎

Semantic recall

Observations are embedded with sentence-transformers and stored in ChromaDB or Qdrant. Before each LLM call, Argus injects the most similar past experiences as context.

⚡

Zero-config or Docker

Works out of the box with local ChromaDB + NetworkX. Upgrade to Qdrant in a single command — Argus spins up a container automatically and reuses it across sessions.

.argus/config.yaml
# Zero-config local backend (default)
knowledge:
  enabled: true
  type: local
  embedding_model: all-MiniLM-L6-v2

# Docker-managed Qdrant (better at scale)
# knowledge:
#   type: docker
#   vector_backend: qdrant

# Install knowledge extras:
# pip install argus-app-testing[knowledge]
Comparison

Why not Selenium / Playwright / Cypress?

Traditional tools are great when the UI is stable. Argus shines when it isn't.

Capability Selenium / Playwright / Cypress Argus
Test authoring Write code with selectors/locators Write plain English
Handles UI changes Breaks when selectors change Adapts like a human tester
Desktop GUI testing Browser only Windows + Linux GUI supported
CLI testing Not supported Built-in CLI adapter
Exploratory testing Manual, or scripted scenarios Autonomous free-roam mode
Vision / screenshots Screenshots only for debugging First-class: LLM sees the screen
LLM provider N/A Ollama (free local) or any cloud API
Install

Get started in 60 seconds

Requires Python 3.10+ and Ollama for free local LLM inference.

Core (any OS)
pip install argus-app-testing
Windows desktop GUI
pip install "argus-app-testing[windows]"
Browser testing
pip install "argus-app-testing[browser]"
playwright install chromium
Linux GUI (X11/Xvfb)
pip install "argus-app-testing[linux]"
Web dashboard
pip install "argus-app-testing[serve]"
argus serve
Everything
pip install "argus-app-testing[all]"
First run 
# Install a free local model
ollama pull gemma3:9b

# Initialize a project
argus init

# Check your provider
argus providers

# Run the example test
argus run
