Universal application testing

Test any software,
any interface

Argus watches your application the way a person would — through screenshots, the accessibility tree, terminal output, and the browser DOM — then drives it to satisfy your tests.

$ argus init
Passed Failed Error Running Skipped Flaky

Three surfaces, one tool

Argus ships as a single installer with a CLI, a desktop app, and a self-hosted web dashboard.
