01 — How it works

From intent to evidence, one boundary at a time.

Argus keeps placement, interaction, policy and verification separate. The model proposes; Argus checks every action before it runs. Assertions are never left to the model's opinion.

02 — Execution environments

        
A hundred eyes on your app. None on your desktop.

        
Adapters decide how Argus interacts with a target. Execution environments decide where it's allowed to. Pick the boundary that fits the risk.

    03 — Adapters
    
        
    One test style. Three ways in.
    
        
    Tests are YAML files in .argus/. Plain-English steps go to the model; assert blocks run deterministically.

      04 — Capabilities
    
    
    
    
      
    intent
    Natural-language actions
    Say what a user should do instead of maintaining brittle selectors for every interaction.
    
      
    verify
    Deterministic assertions
    Visible text, process state, exit code, URL and title are checked without asking the model.
    
      
    policy
    Central execution policy
    Every action is normalized and checked against capabilities and host-safety policy first.
    
      
    windows
    Safe local mode
    Supported desktop actions use semantic UI Automation, not host-wide input injection.
    
      
    isolate
    Disposable Capsules
    Invasive tests run in dedicated VMs with secure guest control and explicit lifecycle ownership.
    
      
    forensics
    Failure Capsules
    Keep disk and config evidence from a failed scripted run, without persisting live credentials.
    
      
    transfer
    Explicit file transfer
    Stage inputs and collect outputs through declared, bounded, hashed transfers.
    
      
    evidence
    ATES v0.1 evidence
    Ordered events, protected artifacts and verifiable manifests. Reports derive from evidence.
    
      
    models
    Any provider
    Ollama locally, or Anthropic, OpenAI, Azure, Gemini and LiteLLM. Vision is auto-detected.
    
    
    
  
    

  
  
    
    
    
      
    
        
    05 — Free roam
    
        
    Let it wander. It writes down what breaks.
    
        
    Give Argus a target and a time budget. It explores without a script, catches crashes and error dialogs, records findings with severity, and leaves you a report plus regression-test stubs. Cross-session memory means each session starts where the last one stopped.
    
        
    $ argus roam "notepad.exe" --minutes 10
    $ argus roam "http://localhost:3000" --adapter browser
    $ argus roam "./my-cli.sh" --adapter cli
    
      
    
      
    
        
    Roaming notepad.exe54 states · 0 findings
    
        
    
        
    → .argus/roam/<stamp>/report.md + regression-*.test.yaml
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    06 — Platform status
    
        
    What's shipped, and what's next. Stated plainly.
    
      
    
      
    Execution authority, evidence authority and future read-only monitoring stay separate trust boundaries.
    
    
    
    
    
      
    Implemented
    ATES v0.1
    Canonical ordered evidence, durable action dispatch, privacy controls, protected artifacts, transactional finalization, manifests and verification, traceability, approvals and audit.

    Node identity and enrollment, authenticated heartbeats, placement and fencing, remote Capsule execution, and ATES transport above the existing Capsule boundary.
