# Argus usability and configuration issue register

Date: 2026-10-07. Status: draft for operator review.

This register supplements PR #29's Environment Matrix plan. It records existing functionality that must become dependable before multiplying executions across environments. It does not declare the matrix implemented or authorize a runtime change.

## Baseline and evidence

- Repository: `Varun-SV/Argus`.
- Matrix planning head: `610d8ad4b3fc4f795f98193c6d541993242c582b` (PR #29).
- Runtime/GUI source examined: `c81a0d3d8a8f747d9dc92597a12405c21362857c` (PR #28).
- Installed package reports `0.1.5`. The seven inspected configuration/adapter/GUI/embedding modules match the PR #28 source after normalizing line endings. This is not a full-package provenance check.
- Original operator configuration and evidence were inspected locally; diagnostics did not change the configuration. Private evidence is retained outside Git.
- Thirty pre-existing ATES reports: 14 error, 11 failed, 4 cancelled, 1 passed. These totals include real assertion failures and user cancellations; they are not thirty proven Argus bugs.
- Nine persisted Roam sessions were inspected. Some session directories have no completed session record; their cause has not been established.
- Existing focused tests: **213 passed**, covering `test_providers`, `test_config`, `test_gui_assistant`, `test_gui_product_readiness`, `test_gui_browser`, and `test_cli_adapter` at the recorded source head.
- Gemini model listing and a small completion succeeded. The configured `gemini-3.5-flash-lite` model is available to this key. Ollama model metadata, health and a small completion succeeded.
- Ollama has `gemma4:e2b` (completion/vision/audio/tools/thinking) and `nomic-embed-text-v2-moe:latest` (embedding). These are different model roles, not two interchangeable chat models.
- Browser and CLI Roam fixture probes each executed one action without an action error, then finalized as cancelled after the probe deliberately requested Stop. These probes prove the execution path exists; they do not establish general autonomous exploration quality.

| ARG-01 | P1 | Provider readiness can look healthy when this process cannot resolve the configured Gemini credential. | Both installed and source `app_info()` return `ok: true`; provider construction fails without an inherited key. Environment inheritance is a setup condition; inadequate readiness reporting is the product gap. | Distinguish project loaded, credential available, endpoint reachable and model capable; provide safe restart/setup guidance. |

## Reproduction status and follow-up

Original Chrome history and owned launch probes, interactive prompt/REPL references, live Gemini/Ollama HTTP Roam with action-effect checks, verified scripted assertion failure, configured knowledge operations and serial browser lifecycle have been reproduced. These establish the defects above; they do not establish fixes or application coverage.

Approved ISO/runtime hashes and the production native-control blocker were verified. ISO-provisioned control remains disabled while protected bootstrap delivery is unsupported. Full native provisioning/boot acceptance remains blocked, and libvirt acceptance needs an eligible Linux host. Approved read-only retained-disk inspection confirmed runtime artifacts and detachment; Sysprep activity with a nonempty error log does not prove successful generalization. Private inspection evidence is retained locally and cannot substitute for boot acceptance.

Private diagnostics remain outside Git. Reproductions use owned benign fixtures. API credentials, target screenshots, original conversation text, private paths and complete configurations are not part of this document.

Detailed safe scenarios and validation limits are recorded in [reproduction results](reproduction-results.md).
